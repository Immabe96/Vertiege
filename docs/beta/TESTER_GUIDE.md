# Vertiege closed beta — tester guide

Thanks for helping test Vertiege before public launch.

## Install

| Platform | How |
|----------|-----|
| **Android (Play)** | Open the **Closed testing** link from the invite email → Accept → Install from Play Store |
| **Android (APK)** | Download the APK we sent → allow install from that app → open **Vertiege** |
| **iOS** | Install **TestFlight** from the App Store → open the TestFlight invite → install **Vertiege** |

## Sign in

- Use **email + password** or **Google** (same as production).
- If sign-in fails, tell us your email and build version (**Settings → About → Version**).

## What to try

1. Complete onboarding / gate if prompted.
2. Join or browse a **world** from Explore.
3. Post, react, and open **chat** in a world channel.
4. Check **Identity** (tier, achievements) and **Nexus** (feed, quests).
5. Turn **notifications** on in Settings and confirm you get alerts when someone interacts (if enabled on server).

## Report issues

Send:

- **What you did** (steps)
- **What you expected**
- **What happened** (screenshot or screen recording helps)
- **Version** from Settings (e.g. `1.1.0-beta.2+6`)
- **Device** (e.g. Pixel 8 / iPhone 15, OS version)

Use the channel your invite specified (email, Discord, etc.).

## Known beta limitations

- In-app purchases may be stubbed or test-only.
- Some voice / LiveKit features may require specific worlds or tiers.
- Rare crashes: reopen the app; they should appear in our crash reports automatically.

## Staff testers only

If you review submissions: sign in normally, then **Settings → Staff review**. You can return to the main app with the back button.
